# **App Name**: Agua Diamante ERP

## Core Features:

- Diseño adaptable: Diseño adaptable que se ajusta a pantallas de móviles y ordenadores.
- Panel general: Panel que proporciona una vista general de métricas clave, como el estado de la producción, el inventario de materias primas y las cantidades de productos terminados.
- Inventario de materias primas: Módulo para rastrear la cantidad de materias primas (por ejemplo, botellas de PET) con alertas para stock bajo.
- Seguimiento de la producción: Gestión de líneas de producción: supervise el estado e ingrese las cantidades de productos terminados. Simule productos terminados basados en líneas de producción activas utilizando IA generativa. La herramienta LLM hará predicciones de cuándo usar las cantidades de uso actuales e históricas al simular la cantidad de producto.
- Autenticación de usuario: Autenticación de usuario para proteger los datos.
- Compatibilidad multiplataforma: Aplicación web que funciona tanto en dispositivos de escritorio como en móviles.
- Gestión de usuarios y roles: Super usuario que puede crear nuevos usuarios y asignar roles específicos.

## Style Guidelines:

- Color primario: Azul claro (#ADD8E6) para reflejar la pureza y claridad del agua.
- Color de fondo: Azul muy claro (#F0F8FF) para crear una sensación limpia y fresca.
- Color de acento: Un azul ligeramente más oscuro (#77B5FE) para resaltar elementos clave y CTA.
- Fuente del cuerpo y del encabezado: 'PT Sans' (sans-serif) para una interfaz moderna y legible.
- Utilice iconos de línea limpios y sencillos relacionados con la producción, el inventario y el agua.
- Diseño claro e intuitivo con un enfoque en la fácil navegación tanto en dispositivos de escritorio como en móviles.
- Transiciones y animaciones sutiles para mejorar la experiencia del usuario sin ser molestas.
- Diseño minimalista con amplios espacios en blanco para una apariencia moderna.
- Tamaños de fuente grandes y legibles para facilitar la lectura en todos los dispositivos.
