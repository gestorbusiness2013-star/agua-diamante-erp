# Preview Workflow for Agua Diamante ERP

This guide describes how to run the development server to preview and test the project locally.

## Step 1: Start the Development Server
Run the Next.js development server:
```powershell
npm.cmd run dev
```

## Step 2: Access the Application
Open your web browser and navigate to:
[http://localhost:3000](http://localhost:3000)

## Step 3: Run Genkit Dev UI (Optional)
If you need to test the Genkit AI flows or developer UI, you can run:
```powershell
npm.cmd run genkit:dev
```
and access it at the port indicated in the terminal.
